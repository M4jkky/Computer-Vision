# Computer Vision Course

This course is available in the third year at the Technical University of Košice in the study programme Intelligent Systems.
There is an assignment in this repository that deals with texture-based segmentation, without using machine learning (the exception was clustering). More information at: https://mosaic.utia.cas.cz
You need to download the images from the output folder, save them in zip format and upload them to: https://mosaic.utia.cas.cz/index.php?act=segm_form
